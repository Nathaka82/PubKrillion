# Knowledge sources

The bundled UN M49 snapshot records each country or area by numeric code and its region, subregion and intermediate region. The builder compares all six UN language tables before publishing. It adds English display names and short forms from Unicode CLDR when the ISO alpha-2, ISO alpha-3 and numeric identifiers agree. The same three identifiers can independently connect a country or area to a unique Wikidata item for readership-based score estimates. New M49 entries can use their UN names and ISO codes immediately. The compressed snapshot supports offline play and the online builder refreshes all three sources. [UN Statistics Division M49](https://unstats.un.org/unsd/methodology/m49/overview/) · [CLDR territory names](https://github.com/unicode-org/cldr-json/blob/main/cldr-json/cldr-localenames-full/main/en/territories.json) · [CLDR identifier mappings](https://github.com/unicode-org/cldr-json/blob/main/cldr-json/cldr-core/supplemental/codeMappings.json) · [Unicode license](unicode-license.txt) · [Wikidata ISO numeric country code](https://www.wikidata.org/wiki/Property:P299)

`pubchem-periodic-table.json` is the published periodic table from the U.S. National Library of Medicine’s PubChem service. Atomic numbers identify members across editions. The independent builder checks this export for changes and uses its standard-state and group fields to generate relationship questions. [PubChem periodic table](https://pubchem.ncbi.nlm.nih.gov/periodic-table/) · [Machine-readable export](https://pubchem.ncbi.nlm.nih.gov/rest/pug/periodictable/JSON)

The general index uses all three transductive splits and the entity and property aliases published by the Wikidata5M authors. The installer verifies the SHA-256 of each archive from a pinned mirror. The graph records relationships at the snapshot date. [Wikidata5M dataset and authors](https://deepgraphlearning.github.io/project/wikidata5m) · [Pinned mirror](https://huggingface.co/datasets/intfloat/wikidata5m/tree/6b2b09672129e280c0c9da97ab58154e9d535e6b)

`wikimedia-en-titles.tsv.gz` adapts Wikimedia's English Wikipedia title mapping from the 30 March 2026 snapshot. It contains 4,683,761 Wikidata IDs and article titles shared with the general index. The projection credits Wikimedia contributors and is distributed under CC BY-SA 4.0. To reproduce it, run `scripts/knowledge/build_world_titles.py` on the pinned English Parquet file with DuckDB and the Wikidata5M index installed. [Wikimedia source and attribution](https://huggingface.co/datasets/wikimedia/wikidata-title-desc/tree/4e2b0b368762a15a3dafd1bcf353825513851695) · [Licence](https://creativecommons.org/licenses/by-sa/4.0/)

The compressed fish projection comes from the FishBase Team’s species, common-names and maturity tables, distributed by Carl Boettiger through Source Cooperative. The release identifier is in `fishbase-release.txt`. The projection preserves scientific and regional names, sex-specific common and maximum lengths, measurement types and documented lengths at first maturity. Fork and standard lengths establish lower bounds for total length. The importer treats reported maxima and sizes at maturity as distinct evidence. The independent publisher checks for later releases and validates the species count before accepting a replacement. FishBase data are available for noncommercial use under CC BY-NC 4.0. [Release and licence](https://source.coop/cboettig/fishbase) · [Species fields](https://fishbase.se/manual/fishbasethe_species_table.htm) · [Maturity fields](https://fishbase.se/manual/FishBaseThe_MATURITY_Table.htm)

`wikidata-quantities.sqlite` is a property-wide projection of Wikidata's length and mass statements. The shipped release holds 369,133 length ranges and 1,689,914 mass ranges. The builder queries the QLever Wikidata replica, excludes statements with qualifiers and uses the best eligible rank. An unqualified normal-ranked value can supply a whole-entity measurement when a preferred statement only describes a particular part or condition. It normalizes recognized units and retains the full uncertainty interval across each item's eligible values. The `release` table records the property IDs and the content digest. Run `python scripts/knowledge/build_world_quantities.py` to regenerate the projection. A completed build replaces the previous file atomically. Wikidata's structured data are available under CC0. [Wikidata RDF representation](https://www.mediawiki.org/wiki/Wikibase/Indexing/RDF_Dump_Format) · [QLever dataset](https://qlever.dev/wikidata) · [Wikidata licensing](https://www.wikidata.org/wiki/Wikidata:Licensing)

The common pear reference uses the usual fruit length reported by Kwantlen Polytechnic University's School of Horticulture. [Common pear](https://plantdatabase.kpu.ca/PlantPrint/pycm)

The Wikidata snapshots contain stable item identifiers, names and structured statements. Each compressed source includes its retrieval metadata. Live updates use the same adapter as the initial projection. Wikidata structured data are distributed under CC0. [Cheese class](https://www.wikidata.org/wiki/Q10943) · [Wikidata licensing](https://www.wikidata.org/wiki/Wikidata:Licensing)

Fish and Wikidata familiarity estimates can use English name frequencies from `wordfreq` 3.1.1, together with multilingual name coverage. These are estimates for an English-language quiz. [wordfreq data and attribution](https://github.com/rspeer/wordfreq#sources-and-supported-languages)

`finals.json` records both sides of each completed final alongside the edition calendar and the original FIFA and WTA source URLs. The pack builder and the knowledge index read the same records.
